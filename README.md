# Delta Egypt Pharmacies Landing Page

Professional, modern, and animated landing page for Delta Egypt Pharmacies (صيدليات دلتا مصر) launching soon in Upper Egypt.

## Project Overview
This project is a single-page landing page built with React and Tailwind CSS, featuring smooth animations and a premium brand identity. It supports Right-to-Left (RTL) layout for Arabic content and is fully responsive.

## Core Features
- Responsive Navigation Bar with scroll effects.
- Hero Section with floating background icons and entry animations.
- Live Countdown Timer for the upcoming launch.
- About Section with statistics counters.
- Services Grid with interactive cards.
- Contact Section with click-to-call and WhatsApp integration.
- Feedback and Complaint Form with validation.
- Social Media connectivity.

## Technology Stack
- React (Functional Components + Hooks)
- Tailwind CSS (Styling)
- Framer Motion (Animations)
- React Hook Form (Form Validation)
- React Icons (System Icons)
- Google Fonts (Cairo for Arabic, Poppins for Latin)

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/mostafamerzk/delta-egypt-pharmacies-landing.git
   ```

2. Navigate to the project directory:
   ```bash
   cd delta-egypt-pharmacies-landing
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## Available Scripts

- `npm run dev`: Runs the app in development mode.
- `npm run build`: Builds the app for production to the `dist` folder.
- `npm run preview`: Locally previews the production build.
- `npm run lint`: Runs ESLint to check for code quality issues.
